# CD-UDepth

## Usage Instructions

Please run `simple_test.py` to execute our CD-UDepth model.

## Pretrained Model

The pretrained model parameters can be downloaded from the following link:

[Download Pretrained Model](https://drive.google.com/file/d/17fJml352PA2X8jdmTy5elcXQed9Nn3Jo/view?usp=drive_link)

After downloading, please place the model parameter file in the `saved_model` directory.

This model uses UDepth as its backbone network. If you encounter any related issues, please refer to the following link:

[UDepth Repository](https://github.com/uf-robopi/UDepth)

## Code Availability

The model code will be released after our paper is accepted for publication.
